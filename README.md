\# neuro-learning



Mis notebooks de práctica de neuroingeniería.



\## Qué no se sube a Git (.gitignore)



\- `.ipynb\_checkpoints/`: copias automáticas que Jupyter genera solo, no aportan nada al historial.

\- `\_\_pycache\_\_/`: archivos que Python genera solo al ejecutar código.

\- `data/`: los datos pesan mucho y GitHub no está hecho para guardarlos.

\- `.env`: guarda contraseñas y tokens, y nunca deben subirse a GitHub.
